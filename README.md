# JISAN TRADER — Learning Bot

A one-line JavaScript bookmarklet prototype for `market-qx.info`.

## Included
- Premium dark/green floating UI
- JT logo
- Drag / move
- Minimize / restore
- Close / duplicate protection
- Market pair detection
- 15-second scan countdown + progress
- Analysis, confirmation, signal, execution, result, explanation, learning log, strategy and statistics sections
- Bengali descriptions with English section headings

## Important
This repository contains a **demo/learning prototype**. The UP/DOWN signal is intentionally mock/random and is **not real AI prediction**. It does not read candle data, calculate verified indicators, backtest, guarantee outcomes, or execute real trades.

## Use
1. Open `bookmarklet.js` in GitHub.
2. Copy the complete single line beginning with `javascript:`.
3. Create/edit a browser bookmark and paste the line into the bookmark URL field.
4. Open the target trading page on `market-qx.info`.
5. Run the bookmark.
6. Press **START NEW SCAN**.

If Chrome removes `javascript:` while saving, type `javascript:` manually and then paste the remaining code.
